5. What is an assignment operator?

6. What are var, let and const?
They are keywords used to declare variables in JavaScript.

7. Difference between var, let and const?
var:

var is the traditional JavaScript variable declaration keyword.
Example: var username = "React";

let:

let was introduced in ES6.
ES6 means ECMAScript 2015.
Example: let city = "Chennai";

const:
const was also introduced in ES6.
const is used when the variable binding should not be reassigned.
Example: const course = "JavaScript";

8.What is ES6?

ES6 introduced many modern JavaScript features.
