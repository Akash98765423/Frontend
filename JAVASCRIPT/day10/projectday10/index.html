Question 01 Level 1: Very Easy

1. Print numbers from 1 to 10.

Write a JavaScript loop that prints sequential integers starting at 1 and ending at 10.

Question 02 Level 1: Very Easy

2. Find whether a number is even or odd.

Check divisibility by 2 in JavaScript using the modulus operator (%) to determine parity.

Question 03 Level 2: Easy

3. Find the largest of two numbers.

Take two numbers as input and compare them using an if-else or ternary operator.

Question 04 Level 2: Easy

4. Find the largest of three numbers.

Compare three values using compound conditions (&&) or Math.max().

Question 05 Level 2: Easy

5. Find the sum of numbers from 1 to 100.

Compute the total sum iteratively using a loop or with the formula n*(n+1)/2.

Question 06 Level 3: Medium

6. Find the factorial of a number.

Calculate n! = n × (n-1) × ... × 1 using loops or recursive functions.

Question 07 Level 3: Medium

7. Reverse a number.

Extract last digits using % 10 and reconstruct the reversed integer.

Question 08 Level 3: Medium

8. Count the digits in a number.

Repeatedly divide the number by 10 or convert to string to find total digit count.

Question 09 Level 4: Tough / Advanced

9. Find whether a number is prime.

Determine if a number is greater than 1 and has no positive divisors other than 1 and itself using Math.sqrt() optimization.

Question 10 Level 4: Tough / Advanced

10. Find whether a string is a palindrome.

Check if a string reads the exact same forwards and backwards using two pointers or regex string cleaning.
